# 🧾 Extractor de Datos de Facturas PDF con Gemini 🤖

Este proyecto permite **leer archivos PDF de facturas** y extraer automáticamente los siguientes datos clave usando **Gemini (Google Generative AI)**:

- 📌 Nombre del proveedor  
- 🆔 RUC / NIT  
- 👤 Razón Social / Nombres y Apellidos  
- 🧾 Número de factura  
- 📅 Fecha de emisión  
- 💰 Monto total  
- 💵 Moneda  
- 🧮 IGV / IVA (si aplica)  
- 📦 Detalles de productos o servicios  

---

## 🚀 Requisitos

- Python 3.8+
- pip
- Cuenta de Google Cloud con acceso a Gemini API

---
